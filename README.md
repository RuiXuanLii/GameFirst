# GameFirst · 2D 武侠小游戏

使用 Godot 开发的单人俯视角武侠游戏。主角穿越到武学时代，在大地图上游历不同地界与门派，修炼心法、学习招数。根骨、悟性、魅力为通常固定的初始资质，仅极少数机缘可以提升；人物能力围绕内力（阴阳）、招数、性格状态三项展开，重视门派传承和招式表现。随身系统能力与战斗控制方式留待后续讨论。

## 当前状态

目前保存的是原始移动原型：角色移动、摄像机和一面碰撞墙。门派、武学、战斗及成长尚未实现。

- 开发环境：Windows，Godot 4.7.2，GDScript。
- 打开方式：用 Godot 导入 `project.godot`，打开 `main.tscn`，按 F6 运行当前场景。
- 操作：W / A / S / D 移动。
- 原始工程尚未设置默认启动场景；第一个开发任务将处理这一点。
