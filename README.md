# GameFirst · 2D 武侠小游戏

使用 Godot 开发的单人俯视角武侠游戏。首版目标是在一座练武场内，通过移动、挥剑和闪避击败三波敌人。

## 当前状态

目前保存的是原始移动原型：角色移动、摄像机和一面碰撞墙。战斗、敌人和结算尚未实现。

- 开发环境：Windows，Godot 4.7.2，GDScript。
- 打开方式：用 Godot 导入 `project.godot`，打开 `main.tscn`，按 F6 运行当前场景。
- 操作：W / A / S / D 移动。
- 原始工程尚未设置默认启动场景；第一个开发任务将处理这一点。
